# Fbox_1 当前不足、终极优化建议与后续拓展规划

## 1. 当前不足（已完成阶段后的客观问题）

### 1.1 架构与代码组织
- 已完成 App 拆分与 `GameOps` 接口化，但仍有改进空间：
  - 尚未引入统一错误码与故障回退页（如 LCD/I2S 初始化失败页面）。
  - 菜单与页面组件仍偏“过程式绘制”，缺少可复用 UI 组件抽象（列表、弹窗、状态条）。

### 1.2 显示与渲染
- 已接入 RGB565 位图块绘制，但文字绘制仍以逐像素字符为主，刷新成本偏高。
- 贪吃蛇虽做了局部刷新，极端情况下仍可能出现可感知的单帧抖动。

### 1.3 输入系统
- 已有消抖、迟滞、repeat、队列化；但缺：
  - 开机自动中心校准（摇杆漂移补偿）
  - 队列溢出统计计数（用于性能诊断）

### 1.4 音频
- 已有事件音+示例旋律，但缺完整“事件混音/优先级/包络”策略。
- 音量控制目前为线性百分比，听感不够线性（建议对数曲线映射）。

### 1.5 存储
- 已有 CRC + 延迟写入策略，但存储对象仍偏少。
- 缺“配置版本升级迁移”流程（新字段兼容老版本配置）。

## 2. 音频终极优化建议（后续优先级高）

### 2.1 目标
- 保持低噪声、低打扰（宿舍/教室环境可用）
- 保证事件音清晰可辨
- 背景音乐与事件音可共存且不互相破坏

### 2.2 建议方案
- 音频事件总线化：
  - 统一 `Audio_PostEvent(event_id)`，由音频服务内部调度。
- 双通道逻辑层（非硬件双通道）：
  - `BGM channel`（循环旋律）
  - `SFX channel`（按键、得分、碰撞）
- 优先级策略：
  - `GAME_OVER/HIT > SCORE > CONFIRM > MOVE`
  - 高优先级事件到来时可中断低优先级 SFX。
- 音量映射：
  - 用户设置 1~100% -> 对数增益表（听感更自然）。
- 包络（最小实现）：
  - Attack 2~5ms，Release 5~10ms，减少爆音。
- 静音策略：
  - `sound_enabled=0` 时彻底停止数据输出并拉低功放使能（如硬件接了 SD）。

### 2.3 验收标准
- 菜单快速操作无明显爆音。
- 贪吃蛇高频得分时音效仍能区分。
- 背景音乐开启时按键音仍清晰。

## 3. 存储终极优化建议

### 3.1 建议扩展存储对象
- `sound_enabled`
- `volume_percent`
- `snake_high_score`
- `brick_high_score`（为打砖块预留）
- `last_selected_menu`
- `input_calibration`（摇杆中心/阈值）
- `settings_version`

### 3.2 建议机制
- 结构体版本化：
  - `magic + version + payload_len + crc32`
- 迁移函数：
  - `Storage_Migrate(v_old -> v_new)`
- 双缓冲区策略（可选）：
  - A/B 区轮转，降低断电损坏概率。
- 写入节流：
  - 游戏结束、设置页退出、显式保存点触发写入。

### 3.3 验收标准
- 反复上电后配置与高分稳定恢复。
- 断电恢复后不会出现“全零配置”或异常值。

## 5. 冻结版硬件资源表（必须落地文档）

> 要求：与代码严格一一对应，后续改动先改文档再改代码。

### 5.1 时钟树（冻结）
- HSE: 8MHz
- SYSCLK: 168MHz
- PLL: M=8, N=336, P=2, Q=7
- APB1: HCLK/4
- APB2: HCLK/2

### 5.2 调试保留策略（冻结）
- `PA13` SWDIO：禁止占用
- `PA14` SWCLK：禁止占用
- 量产前默认保留 SWD，不关闭调试口

### 5.3 外设映射（冻结）
- ST7789 (SPI1):
  - SCK `PA5`
  - MOSI `PA7`
  - CS `PD1`
  - DC `PD15`
  - RST `PD4`
  - BLK `PE8`
- Joystick ADC:
  - X `PA2`
  - Y `PA3`
  - SW：按当前 `keys/gpio` 配置
- UART 调试：
  - USART2（按当前工程配置）
- I2S + MAX98357:
  - WS/LRC `PA4`
  - BCLK `PC10`
  - DIN `PC12`

### 5.4 预留与禁止占用
- 预留：
  - 给打砖块扩展（可能的额外按键/震动反馈）
- 禁止占用：
  - SWD 引脚
  - 当前已绑定关键总线引脚（SPI/I2S/UART）
